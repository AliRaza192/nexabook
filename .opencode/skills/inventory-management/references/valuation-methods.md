# Valuation Methods

## FIFO (First-In-First-Out)
- Oldest stock consumed first
- Tracks cost layers
- More accurate but complex
- Better for inflationary environments

### Example
```
Purchase 1: 100 units @ Rs. 100 = Rs. 10,000
Purchase 2: 100 units @ Rs. 110 = Rs. 11,000
Sale: 150 units

FIFO Cost:
- 100 units @ Rs. 100 = Rs. 10,000 (from Purchase 1)
- 50 units @ Rs. 110 = Rs. 5,500 (from Purchase 2)
Total COGS = Rs. 15,500
```

## Weighted Average
- Average cost of all stock
- Simpler calculation
- Smoothes price fluctuations
- Common in Pakistani businesses

### Example
```
Purchase 1: 100 units @ Rs. 100 = Rs. 10,000
Purchase 2: 100 units @ Rs. 110 = Rs. 11,000

Average Cost = (10,000 + 11,000) / (100 + 100)
             = 21,000 / 200
             = Rs. 105 per unit

Sale: 150 units
COGS = 150 × 105 = Rs. 15,750
```

## Which to Use?
- FIFO: When inventory turnover is high, prices rising
- Weighted Average: When prices fluctuate, simpler tracking
- Consistent: Use same method across all products

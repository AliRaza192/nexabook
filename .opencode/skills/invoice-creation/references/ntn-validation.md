# NTN Validation Rules

## NTN (National Tax Number) Format
- **Length:** 8 digits
- **Type:** Numeric only
- **Example:** 12345678

## Validation Rules
1. Must be exactly 8 characters
2. Must contain only digits (0-9)
3. No leading zeros for companies
4. Individual NTN may differ

## Common Issues
- Missing leading zero
- Extra digits
- Non-numeric characters
- Incorrect format

## NTN Types
- Company NTN: 8 digits
- Individual NTN: 8 digits
- NGO NTN: different format
